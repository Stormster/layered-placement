Decorate with Pickup/Place Furniture without using Brush Tool but the way the admin brush allows.

Hang lights over tables and posters, and put lamps on railings and catwalks. Outdoor and railing lights use battery when there is no building power, so they still turn on when placed where a room has none.

Server owners choose allowed features in Sandbox Options. Players can turn allowed features off for themselves in Mod Options. Crates/tables still stack normally. Skills and tools still matter.

B42.20+. Safe mid-save. Multiplayer supported — enable on the server and all clients. Hosting co-op counts as a server, so enable it in the co-op server's mod list too, or stacking on occupied tiles will do nothing.

COMPANION MOD (optional, not required)

Brush Tool Save Fix — https://steamcommunity.com/sharedfiles/filedetails/?id=3775272983
A separate B42 multiplayer bug: admin Brush Tool tile edits are cosmetic only and revert once the chunk unloads. Layered Placement does not use the Brush Tool and works fine without it, but the two get confused because tiles vanishing looks the same from the outside. If you run a server, use the Brush Tool, and see edits reverting after a relog or restart, that is the one you want.
